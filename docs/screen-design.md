# 서울 문화행사 찾기 — 화면 설계

작성: product-lead · 2026-11-05 · 근거: `docs/research.md`, 기존 코드 `server.mjs`, `public/index.html`, `public/events.js`

## 1. 목적과 완료 기준

서울에서 열리는 문화행사를 **구 · 날짜 · 무료 여부**로 걸러 **카드 목록**으로 보여 준다.

완료 기준:
- 세 필터가 각각, 그리고 함께(AND) 동작한다.
- 결과가 카드로 보이고 결과 수가 표시된다.
- 불러오는 중, 결과 0건, 불러오기 실패일 때 사용자가 다음에 할 일을 안다.
- 360px 폭부터 데스크톱까지 가로 스크롤 없이 보인다.
- `npm test`로 필터·무료 판별 규칙이 검증된다.

범위 밖: 로그인, 즐겨찾기, 지도, 상세 페이지, URL 공유 상태, 페이지 나누기(데이터가 323건이라 필요 없음), 실시간 API 호출(인증키는 사용자 계정 행위).

## 2. 구조 (현재 구조 유지)

- `npm start` → `server.mjs`(의존성 없는 Node 22 서버, 포트 5180)가 `public/`을 서비스하고 `GET /api/events`로 `data/events.json`(2026-10-31 스냅숏, 323건)을 돌려준다.
- 브라우저에서 Open API를 직접 부르지 않는다(CORS 없음, HTTP 8088 — research §2).
- 필터·표시 규칙은 `public/events.js`의 순수 함수에 두고(DOM 없음), 화면은 `public/index.html`에서 그린다. 테스트는 `events.js`를 직접 import한다.

### 3.1 필터
| 필터 | 컨트롤 | 기본값 | 규칙 |
|---|---|---|---|
| 구 | `<select>` — `전체 (N)` + 데이터에 있는 구를 가나다순, 구별 건수 표시 | 전체 | `GUNAME` 정확 일치. **`GUNAME`이 빈 행은 `기타` 항목으로 묶는다** (지금은 값이 `''`라 "전체"와 같은 value의 이름 없는 항목이 생기는 버그가 있다). `기타`는 목록 맨 끝 |
| 날짜 | `<input type="date">` + **[오늘] 버튼** | 비어 있음(전체 기간) | 선택한 날이 `[STRTDATE, END_DATE]` 안에 있으면 표시(앞 10자 `YYYY-MM-DD` 문자열 비교, 시간대 변환 없음). [오늘]은 브라우저 로컬 날짜로 채운다 |
| 무료 | 체크박스 "무료만 보기" | 해제 | `IS_FREE === '무료'`만. `USE_FEE`로 판별하지 않는다(research §5) |
| 초기화 | 버튼 | — | 세 필터를 기본값으로, 포커스를 구 선택으로 |

필터 변경 즉시 갱신(검색 버튼 없음).

### 3.2 카드
1. 사진(`MAIN_IMG`, 4:3). 실패하거나 4초 안에 안 뜨면 `public/fallback/*.jpg` 대체 그림. **대체는 그 카드에만 적용**한다 — 지금 코드의 `photosDown` 지름길(사진 하나가 실패하면 이후 모든 카드가 대체 그림)은 없앤다. 대체 그림 고르기는 무작위 대신 분류(`CODENAME`)에 맞추거나 행사 키로 결정적으로 고른다.
2. 배지: **무료**(초록)/**유료**(회색) — 글자로도 구분 + 분류(`CODENAME`).
3. 제목 — `HMPG_ADDR`, 없으면 `ORG_LINK`(http/https만) 링크, 새 탭. 링크가 없으면 일반 텍스트.
4. 기간: 하루짜리면 날짜 하나, 아니면 `시작 ~ 끝`. **종료일이 2099년 이후 같은 비정상 값이면 `시작 ~ 상시`**로 표시(research §5의 2626-08-08, 2099-12-31).
5. 장소 · 구.
6. 요금: `USE_FEE` 원문, 비면 무료는 "무료", 유료는 "요금 정보 없음".
7. 이용 대상(`USE_TRGT`, 있으면).

정렬: **종료일이 가까운 순**(곧 끝나는 행사 먼저), 같으면 시작일, 그다음 제목 순.

### 3.3 상태
| 상태 | 표시 |
|---|---|
| 불러오는 중 | "행사를 불러오는 중…" (지금은 빈 화면) |
| 결과 0건 | "조건에 맞는 행사가 없습니다." + [필터 초기화] (현재 동작 유지) |
| 불러오기 실패 | 안내 문구 + **[다시 시도]** 버튼 |

## 4. 시각 · 접근성
현재 `public/style.css`를 유지한다(시스템 폰트, 흰 카드, 초록 무료 배지, 포커스 링, 480px 이하 필터 세로 배치). 모든 컨트롤에 label, 결과 수 `aria-live`, 사용자 데이터는 `textContent`로만 넣는다.

## 5. 해야 할 일 (build 체크리스트)
1. `GUNAME` 빈 값 → `기타` (필터·건수·카드 표시).
2. [오늘] 버튼.
3. 종료일 비정상 → `상시` 표시.
4. 종료일 순 정렬.
5. 사진 대체를 카드별로 (`photosDown` 제거), 대체 그림 결정적 선택.
6. 불러오는 중 표시, 실패 시 [다시 시도].
7. `scripts/fetch-events.mjs`의 하드코딩 인증키 제거 → `process.env.SEOUL_API_KEY`만 사용 (research §6).
8. `test/events.test.js` — `node --test`로 무료 판별, 구 필터(기타 포함), 날짜 경계(시작일·종료일 당일 포함), 필터 조합, 정렬, 링크 선택, 기간 표시(상시)를 검증.
