## 결론

**수정 필요 — 데이터 갱신 스크립트의 인증키가 HTTP 요청 경로로 평문 전송됩니다.** 정적 스냅숏을 제공하는 앱 경로에는 이 키가 필요하지 않아 앱 자체와 분리된 운영 위험입니다. 키를 실제로 사용하는 환경에서는 TLS 경유 방법을 마련하거나, 불가피하다면 신뢰된 네트워크에서만 제한된 키로 실행해야 합니다.

## 발견

### MEDIUM — API 인증키가 평문 HTTP로 전송됨

- 위치: `scripts/fetch-events.mjs:12-15`
- 근거 및 결과: 키는 현재 코드에 하드코딩되어 있지 않고 `SEOUL_API_KEY` 환경변수에서 읽습니다. 그러나 URL을 `http://openapi.seoul.go.kr:8088/.../${KEY}/...`로 만들고 그대로 `fetch`합니다. 이 요청 경로는 TLS로 보호되지 않아 네트워크 경로를 관찰할 수 있는 주체가 키를 복사해 API를 호출할 수 있습니다. `docs/research.md` §2는 이 서비스 포트의 HTTPS 요청이 연결 실패했다고 기록합니다. 키 값은 이 리뷰에 기록하지 않았습니다.
- 권장: 키를 보호하는 HTTPS 지원 프록시/전송 경로가 있는지 확인해 사용하세요. 공급자가 HTTP만 제공한다면 이 스크립트의 실제 키 사용을 신뢰된 네트워크로 제한하고, 사용량 제한이 있는 키를 사용하며 노출 시 재발급하세요. 현 저장소에서는 키 문자열 하드코딩을 발견하지 못했습니다.
- 범위: `npm start`와 브라우저 앱은 로컬 `data/events.json`을 제공하므로 이 키 전송 경로를 사용하지 않습니다.

## 확인한 규칙과 구현

- 구 필터는 `GUNAME` 정확 일치이며 빈 값/공백은 `기타`로 정규화합니다. 필터·건수·카드가 같은 `guOf`를 사용합니다.
- 날짜 필터는 `STRTDATE`/`END_DATE` 앞 10자를 비교해 양 끝 날짜를 포함하며, 무료 필터는 `IS_FREE === '무료'`만 사용합니다. 세 조건은 AND입니다.
- 정렬은 종료일, 시작일, 제목 순이고 원본 배열을 변경하지 않습니다. 2099년 이상 종료일은 `상시`로 표시합니다.
- 카드 텍스트는 DOM 생성 후 `textContent`로 삽입합니다. 외부 링크는 HTTP(S)만 선택하고 새 탭 링크에 `noopener noreferrer`를 지정합니다. 사진 URL은 `<img src>`에만 사용됩니다.
- 이미지 실패/타임아웃은 해당 카드의 이미지 요소만 대체합니다. 재시도 이벤트 핸들러는 `wired` 플래그로 한 번만 등록됩니다.
- 조사한 스냅숏에서 `TITLE+DATE` 중복은 0건이며 종료일 비정상 미래 값 2건, 빈 구 1건이 설계 문서와 일치합니다.
